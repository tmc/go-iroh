# iroh compatibility harness

This nested module runs wire-compatibility scenarios between go-iroh and pinned Rust iroh releases and pre-release commits. A passing cell requires a real Rust process and records its PID and binary SHA-256.

Run the matrix from a clean checkout with Docker:

```sh
make parity
```

This builds the released Rust peers and the focused pre-release vector driver, then runs them with the Go runner through Docker Compose. The release and pre-release pins are declared together in `pins.env`. Developers with native pinned binaries can use `make parity-native` and set `RUST_DOCTOR_BIN`, `RUST_VECTOR_BIN`, and `RUST_PRE_VECTOR_BIN` explicitly.

The command writes schema `go-iroh-parity/4` to `results/results.json`, updates `results/badge.json`, and renders the repository-root `COMPATIBILITY.md`. Released and pinned pre-release evidence appears in version columns; the advisory nightly tip report is emitted separately as `COMPATIBILITY-tip.md` and `results/tip.json`.

The committed L0 corpus is generated by the pinned Rust test driver. Ordinary tests are offline and pure Go:

```sh
make vectors       # regenerate with Rust and require byte identity
go test ./vectors  # verify the committed corpus with Go only
```
